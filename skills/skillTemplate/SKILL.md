# Skill Template

This is a reusable template for creating new AI skills. Use this as a starting point to define the objective, constraints, approach, and next steps for any new skill you want to add.

## Objective

Describe the main goal or purpose of the skill.

## Constraints

List any limitations or requirements that must be considered.

## Approach

Outline the strategy or methodology for implementing the skill.

## Next Steps

Detail the immediate actions or tasks needed to develop the skill further.
